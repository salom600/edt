# Assets

This directory holds bundled assets: icons, sample media, etc.

For v0.1.0 it contains only this placeholder. Future releases will
add:

- `edt.png` — Linux icon (256x256 PNG)
- `edt.icns` — macOS icon bundle
- `edt.ico` — Windows icon
- `splash.png` — splash screen (optional)
- `sample-project.json` — demo project
