# Architecture Decision Records

This directory contains ADRs for edt. Each ADR documents a single
architectural decision, its context, and its consequences.

The format is based on [Michael Nygard's template](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
